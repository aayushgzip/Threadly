# Threadly - TypeScript Bulletin Board

A Next.js and Firebase Studio powered bulletin board application built with TypeScript for creating and viewing announcements.

## Getting Started

1.  Clone: `git clone <REPOSITORY_URL>` & `cd Threadly`
2.  Install: `npm install` or `yarn install`
3.  Configure Firebase Studio and `.env.local`.
4.  Run: `npm run dev` or `yarn dev`

## Key Features

* Create and display announcements.
* Built with TypeScript and Next.js.
* Integrated with Firebase Studio.

## Technologies

Next.js, TypeScript, Firebase Studio, Firebase.
