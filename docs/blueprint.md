# **App Name**: Eventide Board

## Core Features:

- Announcement Posting: Allow users to create and post announcements with titles, descriptions, dates, times, and locations.
- Announcement Display: Display announcements in a feed, sorted by date with options to filter by category or location.
- Voting System: Enable users to 'upvote' or 'downvote' announcements to increase visibility of more relevant posts.
- Commenting System: Allow users to comment on announcements to ask questions or provide feedback.
- Automatic Category Tagging: Use a tool to analyze announcements and tag them with relevant categories automatically.

## Style Guidelines:

- Primary color: Light gray (#F7F9FA) for a clean background.
- Secondary color: White (#FFFFFF) for content containers.
- Accent: Teal (#008080) for interactive elements and highlights.
- Reddit-style layout with a feed of announcements.
- Use clear and simple icons for voting, commenting, and sharing.
- Subtle animations for upvotes, downvotes, and new announcements.
